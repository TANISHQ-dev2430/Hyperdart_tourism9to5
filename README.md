# 🌍 Tourism Explorer (`@tanishq1741/tourism`)

A travel companion and tourist sight discovery component built for **HyperDart**.

## 🚀 Quick Highlights
- 📍 **Smart Location Resolution**: Resolves coordinates & places dynamically from search queries.
- 🌤️ **Live Weather**: Instant temperature, wind speed, and weather condition badges via Open-Meteo.
- 🏛️ **Authentic Sights & Attractions**: Powered by Geoapify Places API with intelligent name-cleaning and radius selection (5km–50km).
- 🏷️ **Category Filtering**: Explore by *Sights*, *Museums*, *Heritage*, and *Religion*.
- 🗺️ **Dual View Modes**: Switch between Split List + Minimap and Full Interactive Map view.
- 🌐 **On-Demand Translation**: Translates place names (French, Spanish, Japanese, etc.) into English with 1-click.
- ❤️ **Saved Places / Wishlist**: Persists favorite sights locally with direct Google Maps navigation links.
